# Images du site

Déposer ici les visuels client (pas de banque d'images).

## Attendus

- `hero.webp` — intervention de nuit ou plateau (hero accueil, priority)
- `plateau.webp` — véhicule sur plateau
- `equipe.webp` — équipe / gilet haute visibilité
- `materiel.webp` — matériel de dépannage

Format recommandé : WebP ou AVIF, largeur max 1600 px.

Les fichiers manquants restent des placeholders `TODO-PHOTO-REELLE` dans les composants.
